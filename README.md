# 🛒 Avito Shopper Bot

Телеграм-бот, который **ищет на Авито любой товар под тебя**: ты описываешь желаемое
обычным текстом, бот уточняет фильтры кнопками, мониторит Авито и присылает
уведомления только тогда, когда объявление реально соответствует твоим требованиям.

> Принцип: бот не просто выдаёт ссылки, а **проверяет каждую карточку** — сверяет
> характеристики объявлений с твоими требованиями и отсекает брак («на запчасти»,
> «разбит экран», «залит» и т.п.). По ходу поиска ты отвечаешь (reply) на уведомления
> («не подходит, потому что …»), и бот учитывает это в дальнейшем поиске.

## Возможности

- **Живой диалог:** «найди мне ноутбук 16/512, asus/redmi, цена 40–70к, Ryzen но без U-серий» →
  бот собирает профиль поиска (категория, бренды, бюджет, требования must/must_not) и
  при нехватке данных задаёт уточняющие вопросы кнопками.
- **Города и Авито Доставка:** при старте всегда уточняются города (по умолчанию —
  Новокузнецк); если выбраны другие города — бот спросит про Авито Доставку.
- **Разбиение по брендам:** несколько брендов в запросе → несколько отдельных поисковых
  фраз (больше охвата, чем один общий запрос).
- **Сверка характеристик:** бот открывает карточку лота, сверяет бренд, память, процессор,
  экран и т.д. с требованиями профиля, ловит зарезервированные лоты и явный брак.
- **Фидбэк через reply:** ответь на уведомление и объясни, почему лот не подходит —
  бот внесёт это в профиль поиска.
- **Управление поисками:** кнопки «пауза/завершить» прямо в уведомлениях,
  `/searches` — список всех поисков.
- **Заявки на доступ:** чужой человек пишет боту → владельцу приходит заявка
  с кнопками «✅ Дать доступ / ❌ Отклонить».
- **Mini-app сайт:** все найденные лоты в браузере — просмотр, скрыть/показать,
  избранное; поиски — возобновить, остановить или удалить.
  (порт настраивается в `config.json`, по умолчанию 8080)

## Установка (одна команда)

```bash
git clone https://github.com/GrinRonm/avito-shopper-bot.git && cd avito-shopper-bot && bash install.sh
```

Скрипт создаёт virtualenv, ставит зависимости, качает Chromium для Playwright
и копирует шаблон `config.json` (если конфига ещё нет). Дальше вставь свои токены
и запусти:

```bash
venv/bin/python bot.py
```

Windows — то же самое через `install.bat` и `venv\Scripts\python bot.py`.

### config.json

| ключ | что это |
|---|---|
| `telegram_bot_token` | токен бота от [@BotFather](https://t.me/BotFather) |
| `allowed_chat_ids` | chat_id владельцев (они подтверждают заявки и всем остальным нужен апрув) |
| `beatapi_url` / `beatapi_key` / `beatapi_model` | доступ к нейросети (BeatAPI, модель типа `deepseek-v4.1-flash-free`) |
| `edge_path` | путь к msedge.exe (Windows). На Linux игнорируется — используется Chromium |
| `headless` | работа без GUI. На Linux по умолчанию включается |
| `check_interval_seconds` | период скана Авито |
| `pages_first_pass` / `pages_regular` | страниц за круг при первом запуске / далее |
| `max_card_inspections_per_cycle` | сколько лотов за цикл бот открывает в карточку |
| `notify_close_matches` | уведомлять о «возможно подойдёт» (🟡) |
| `default_city_slugs` | города поиска по умолчанию |
| `web_port` | порт mini-app сайта |

## Развёртывание на сервер (Linux, без GUI)

```bash
git clone https://github.com/GrinRonm/avito-shopper-bot.git && cd avito-shopper-bot && bash install.sh
nano config.json                                    # вставь свои токены
nohup venv/bin/python bot.py > bot.out 2>&1 &
```

Мини-app сайт поднимается вместе с ботом на `http://<ip_сервера>:8080`.
Логи пишутся в `bot.log`.

> ⚠️ Авито следит за автоматизацией: с IP сервера капчи случаются чаще, чем с
> домашнего. Если ловишь пустые страницы — уменьши частоту скана или крутите
> частоту через `check_interval_seconds`.

## Архитектура

```
bot.py         телеграм-бот (aiogram 3): диалог, кнопки, фоновый скан-цикл, заявки доступа
ai.py          нейросеть (BeatAPI): план поиска, уточнения, скрининг, сверка карточек, фидбэк
avito.py       скрейпинг Авито через Playwright (листинги по городам и фразам, карточки)
webapp.py      mini-app сайт (aiohttp): лоты + управление поисками
categories.py  известные категории и города Авито (slug'и для URL)
db.py          SQLite: профили поисков, лоты, уведомления, доступы
```

## Стек

- aiogram 3.x
- Playwright (Edge на Windows / Chromium на Linux)
- BeatAPI (DeepSeek/Gemini-совместимый бесплатный эндпоинт)
- SQLite (файл `shopper.db`, WAL)
